# Boulevard (Alpha)

Boulevard is a simple front-end framework for static websites. 

It's based on HTML, CSS, and JavaScript I've written for my own [personal site](https://pmckay.com) and its accompanying [blog](https://blog.pmckay.com). Those sites are effectively my development laboratories, then I re-share elements back into Boulevard as warranted over time.

Boulevard is (and always will be) free to use under MIT license. I welcome feedback, pull requests, bug reports, and other collaboration via GitHub.
